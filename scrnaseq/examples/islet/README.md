# 胰岛专题示例

PFOS/WT 对比、激素排除列表、焦点基因、MIA 参考、胰岛 marker 与配色均留在本目录，不进入通用核心默认值。`example_parameters.yml` 仅列专题参数，不是可直接执行的完整项目配置；按真实样本表填入独立生物学身份后再决定推断资格。`markers_flat.yml` 可作为核心 markers 的完整输入，但自动 marker 标签仍需人工复核；原始层级 marker 与 gene_sets 同时保留用于来源核对。

`optional/` 是来源扩展的参考源码档案，包括 velocity、通讯、GRN、富集及 beta 专题，以及原始 MIA 注释/配色实现。它们不被打包、导入或执行，仍依赖原专题运行上下文，**不是已迁移验证的可运行模块**。本轮验证状态均为 `not_run`。若未来启用，需要单独移植输入接口、设计和依赖后验证，不可在核心中加入原项目路径回退。

velocity / pySCENIC 环境清单单独存放，Python 版本可不同于核心；通讯/富集扩展原依赖包括 `liana>=1.6,<2`、`gseapy>=1.1,<1.2`，beta 绘图需 `seaborn>=0.13,<0.14`。核心不要求这些依赖，不会自动安装。原始单库场景源码中的 n=1 边界只属于该示例，不能推广成新项目的设计结论。

`optional/replot.py`、`source_plotting.py` 与扩展源码记录本轮来源项目的 107 图纯绘图实现；`figure_style.py` 为统一导出规范副本。来源项目已实际完成 107 对重绘，但本目录仍是未独立移植执行的参考档案，不能把来源项目验收等同于本示例验收。
